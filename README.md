# Sabbir Ahmed — Personal Portfolio

An ultra-minimalist, editorial-style personal portfolio engineered for high-performance and strict visual hierarchy. Designed to bridge the gap between academic research and practical software engineering.

## ⚡ Design Philosophy

This portfolio departs from standard web templates and embraces a brutalist, Apple/Linear-inspired aesthetic. It relies entirely on:
- **Pure Black & White**: `#000000` backgrounds and `#FFFFFF` typography. No gradients, no glassmorphism, no visual noise.
- **Extreme Typography Hierarchy**: Oversized, bold headings paired with crisp, tracking-adjusted secondary text.
- **Intentional Whitespace**: Vast margins and padding to create a premium, uncrowded reading experience.
- **Output-Oriented Content**: Focuses exclusively on deployed projects, published research, and quantifiable global recognitions.

## 🧠 Core Focus Areas

- **Cybersecurity**: Network Analysis, Security Research, System Architecture.

## 🛠 Technical Architecture

Built with modern web standards focused on speed, fluid micro-interactions, and maintainability.

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animation Engine**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: Configured for Vercel / Netlify

## 🚀 Local Development

To run this project locally on your machine:

1. **Clone the repository**
   ```bash
   git clone https://github.com/Tony1254-CS/portfolio.git
   cd portfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📋 Sections Overview

- `HeroSection`: Dominant typography and positioning statement.
- `ProofOfWorkSection`: Data-driven metrics of research and competitions.
- `WhatIDoSection`: Concrete breakdown of technical capabilities.
- `FeaturedProjectsSection`: Dual-column layout for major engineering projects (AION, NeuroMirror, PARALLEL).
- `ResearchSection`: Academic publication history.
- `SkillsSection`: Domain-categorized technical stack.
- `ContactSection`: Minimalist, high-conversion social and email links.
